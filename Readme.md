# 🛒 ECommerceLite

> ⚠️ **WORK IN PROGRESS — UNDER ACTIVE DEVELOPMENT**

ECommerceLite is a **microservices-based e-commerce backend** built with **.NET**, designed as a learning and portfolio project focused on real-world backend architecture, service-to-service communication, authentication, and distributed systems.

🚧 **This project is NOT production-ready yet.**  
Features, architecture, integrations, and service communication are still actively being developed and changed.
